HTU Connect 2.0.0 桌面测试版，支持 Windows、Linux、macOS，已移除 Android。

- 认证、门户校验、网络检测及定时决策统一为 Rust 核心。
- 三个桌面系统使用同一个 Python 宿主，CLI 共享其 API 和配置。
- 检测只检测，登录只走一条协议流程；元数据失败不会继续认证。
- 停止状态持久保存；状态刷新不重新探测；日志展示与导出复用同一结果。
- 重做独立 Toolbox WebUI，提供侧边栏导航、移动端抽屉、主题及密度设置，并修复表单同步、操作反馈和键盘导航。
- 图标使用本地 Lucide 资源与 Morphicons 动画，离线可用，并支持减少动态效果的系统设置。
- 后台服务已运行时，再次打开 Setup 会直接打开实际服务端口的网页，避免重复启动和实例锁报错。
- 修复停止自动登录、登出校园网按钮样式，以及已连接服务指示点的绿色显示。
- 删除重复认证脚本、启动器、独立 CLI 配置、备用构建与两套配色。
- 发布包按系统和架构提供，包含核心与 CLI；需 Python 3.10+。

2.0 需重新配置账号密码。系统自启与迁移步骤见压缩包 README。

Windows 已验证真实校园认证、用户计划任务启动后台服务及恢复自动登录；未执行系统重启或注销。Linux、macOS 的真实校园认证和登录自启仍需在相应设备验证。
