本次增加 Android 原生客户端与 Linux/macOS 本机服务，并重构桌面控制台、修复网络认证和配置保存问题。

下载与使用：

- `htu-connect-v1.3.1-debug.apk`：Android 8.0+ 原生应用，版本 1.3.1，使用调试签名。安装后连接校园 Wi-Fi，填写账号与门户地址，保存并连接。后台自动登录需要允许通知。
- `htu-toolbox-desktop-v1.3.1.zip`：Windows 10/11 运行 `Setup.cmd`；Linux/macOS 运行 `bash scripts/start.sh`。桌面端需要 Python 3.10+，账号设置通过本机网页完成。
- `SHA256SUMS`：安装包的 SHA-256 校验值。Android 源码与完整开发文件可通过本 Release 的源码归档下载。

改进与修复：

- Web UI 增加响应式布局和深浅主题，文案改为简短的功能说明。
- 桌面服务拆分为配置、网络、后台任务、Windows 适配和 HTTP API 模块；Linux/macOS 可安装用户自启服务。
- Android 使用 Kotlin 原生控件、Keystore 密码加密和带通知的前台服务，支持手动检测、登录、启停及可选开机恢复。
- 修复网络超时漏报、公网探针误判、账号后缀重复和重复认证；限制门户地址，避免把凭据发送到非校园门户。
- 配置保存增加类型校验、原子写入和失败保留；Windows 安装失败回滚配置及任务，单次登录失败返回非零退出码。
- 本机 API 增加令牌与来源检查，限制请求体和日志读取量；处理浏览器取消请求时的断开连接。
- Rust CLI 失败正确返回错误码，默认执行完成后退出，提供可选 `--pause`。
- 桌面包补齐 Python 模块、依赖与 Rust 锁文件，修复缓存清理和跨平台隐藏文件压缩导致的打包失败。

验证：23 项 Python 测试、4 项 Rust 测试、3 项 Android 单元测试通过；GitHub Actions 的 Windows、Linux、macOS 桌面测试与 Rust 检查通过；APK 签名验证通过，Android 11 软件模拟器完成安装、启动和 UI 截图。桌面 UI 已检查手机宽度、深色主题和 Windows 设置显示。Android SDK lint 无错误，保留一项目标版本警告。

这是跨平台测试版。真实校园网认证、Windows/macOS 系统自启和 Android 真机后台运行仍需在对应设备上验证。标准 Gradle 构建在当前云环境受 Maven 下载限制，本次 APK 由已校验的 Android SDK 与 Kotlin 编译器生成。Rust CLI 的独立 TOML 配置仍保存明文密码。
